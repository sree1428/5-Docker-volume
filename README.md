# Task Manager App

## What it does
Simple task tracking API.

## What the developer needs from DevOps:
- Node.js runtime (v20 works)
- PostgreSQL database
- Environment variables:
  - DB_HOST
  - DB_PORT
  - DB_USER
  - DB_PASSWORD
  - DB_NAME
  - PORT (default 3000)
- App listens on port 3000
